# 证据清单与时间线模板

## 一、立即保全(按优先级)

- [ ] **线上预约确认**:确认邮件/短信/App 页面**完整截图**(须含店址 2833 Broadway、日期时间、疫苗种类、患者信息、任何"费用/无需付款"字样);另存 PDF;原始邮件不要删。
- [ ] **CVS 账户预约记录**:登录 cvs.com/App,截取预约历史页(即使已被标记取消/未到场,截下来——若 CVS 事后改动状态,前后对比反而是证据)。
- [ ] **事前确认 VFC 的细节**:哪一天、几点、店内哪个位置、对方性别/年龄段/工牌特征、原话("Yes, we take VFC"之类)。写成签名+日期的书面回忆。
- [ ] **当日到场凭证**:地铁/打车记录、附近消费小票、手机定位时间线(Google Maps Timeline 可导出)。
- [ ] **涉事员工信息**:姓名/工牌/体貌、当班时间(2026-07-30 [____时])。药剂师排班可由 OPD/DOHMH 调查时向 CVS 调取,你记不全没关系,时间段准确即可。
- [ ] **证人**:同行家人/在场顾客,请其独立写下所见所闻(尤其"大声嘲讽"一节:听到的原话、音量、当时距离、是否有其他顾客在场),署名+日期。
- [ ] **损失清单**:交通费、误工(请假记录/工资单)、改约他处的额外成本、接种延误天数。
- [ ] **就医补救记录**:孩子最终在何处何时完成接种(证明"延误"的终点)。

## 三、录音与取证的法律边界(纽约)

- **可以**:纽约是一方同意州(Penal Law §§ 250.00/250.05)——**你本人参与**的当面对话、电话,可不告知对方直接录音;录音可用于法院、CCHR、OPD 等程序。此后每次与 CVS/药房的沟通建议全程录音。
- **不可以**:把手机/设备留在店内录**你不在场**的员工谈话——构成非法窃听(E 级重罪),千万别做。7 月 30 日的嘲讽是你亲耳所闻,以证词+证人形式呈现即可。
- **通话日志**:每通电话记下日期、时间、号码、对方姓名/工号、要点、承诺与期限;挂断后立即补记。
- **书面优先**:能用邮件/表单就不要只打电话;打了电话就当天发一封"确认今日通话内容"的跟进邮件,把口头承诺钉在纸面上。

## 四、常见坑

- **不要**在社交媒体先发帖点名指控——维权期间公开发言可能被对方律师利用,等有官方结论再说。
- **不要**同一事实先提交 CCHR 又去法院起诉(选择救济规则,二选一);拿不准就先走 DOHMH/OPD/AG/CVS 这些不冲突的渠道。
- **不要**接受口头和解——任何补偿/道歉/纠正承诺都要书面。
- **不要**为了维权推迟孩子接种:先打 347-396-2400 找到最近 VFC 接种点完成接种,延误损失照记。
